2

PPT 교안

될 수도

먼저 1차시 프롬프트 2-1을 그대로 넣어 보세요. 파일이 안 나오면 아래 방법으로.

대신 쓰는 프롬프트 — 슬라이드 개요
위 강의안을 PPT [10]장 분량의 개요로 바꿔줘. 장마다: 제목(10자 이내) / 화면에 크게 넣을 문장 1개(20자 이내) / 넣을 그림 설명 / 강사가 할 말. 쉬운교안지침.txt를 따라줘.
  1. Gamma(gamma.app) → 새로 만들기 → 텍스트 붙여넣기 → 개요 붙여넣기 — 또는 Canva의 프레젠테이션 · 미리캔버스
  2. 글자 크기를 32pt 이상으로 키우고 PPT로 내려받기
3

스킬 대신 — 프로젝트 지시사항

대신
클로드스킬(easy-lesson.zip)을 업로드
챗GPT왼쪽 프로젝트 → 새 프로젝트 → 지시사항에 규칙 붙여넣기 → 그 프로젝트 안에서 대화
  1. 프로젝트 이름: 쉬운 교안
  2. 지시사항에 쉬운교안지침.txt 내용 붙여넣기 (2차시에 만든 SKILL.md가 있으면 그 내용)
  3. 프로젝트 파일에 대상카드.txt 추가 — 무료는 파일 수 제한이 있어요

⚠ 챗GPT의 GPTs(맞춤형 GPT)는 개인 계정에서 새로 만들 수 없고, 2026년 12월 종료 예정이라 안내하지 않아요.

4

커넥터(MCP)

무료 불가

챗GPT 무료는 커넥터를 직접 추가할 수 없어요. 유료(Plus 이상)의 개발자 모드에서만 일부 가능합니다.

  • MCP는 클로드 무료에서 체험 (1차시 5번) — 사용자 정의 커넥터 1개까지
  • 챗GPT에서는 결과 글을 복사해서 카톡에 붙여넣기로 대신
5

웹교안 — 캔버스

그대로
클로드아티팩트 창에 바로 미리보기
챗GPT프롬프트 첫 줄에 "캔버스로" → 캔버스 오른쪽 위 미리보기(▶)
첫 줄만 바꿔서
캔버스로, 위 1회기 강의안으로 이용인이 휴대폰으로 보는 웹교안을 HTML 파일 하나로 만들어줘. (나머지는 2차시 프롬프트 1과 같이)

→ 기능 ①②③(읽어 주기 · 도장 · 반응형)은 2차시 2번 프롬프트 그대로.

6

파일로 받기 → 버셀 · QR

그대로
  1. 캔버스의 코드 복사 (또는 이 HTML을 index.html 파일로 내려받게 해줘)
  2. 메모장에 붙여넣기 → 다른 이름으로 저장 → 파일 형식 모든 파일, 인코딩 UTF-8, 이름 index.html
  3. 웹교안 폴더에 넣고 → 버셀에 올리기 → QR은 2차시 4번과 같이
🛟 한글이 깨지면 저장할 때 UTF-8을 골랐는지 · 코드가 그대로 보이면 이름이 index.html.txt가 되지 않았는지

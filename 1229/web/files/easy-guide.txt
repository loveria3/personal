[쉬운 교안 지침] — 발달장애인 주간활동·방과후 교육자료용
(이 파일을 클로드에 올리고 "이 지침대로" 라고 말하면 됩니다)

■ 글
- 한 문장에는 한 가지 내용만. 문장은 짧게 (15자 안팎).
- 쉬운 낱말을 씁니다. 어려운 말·한자어·영어는 쉬운 말로 바꿉니다.
  예) 결제 → 돈 내기 / 확인 → 보기 / 이용하다 → 쓰다
- "~하지 마세요"보다 "~해요"처럼 할 일을 말합니다.
- 숫자는 아라비아 숫자로 씁니다. (셋 → 3)
- 존댓말을 씁니다. 반말·아이 취급하는 말은 쓰지 않습니다.

■ 화면 (PPT·웹교안 공통)
- 한 장(한 화면)에 메시지 하나.
- 글자는 크게: PPT 제목 44pt 이상, 본문 32pt 이상 / 웹 본문 22px 이상.
- 글자와 배경은 진하게 대비 (흰 바탕 + 진한 남색 글씨).
- 그림·사진·큰 이모지를 글 옆에 함께 둡니다. 그림만 보고도 뜻을 알 수 있게.
- 순서가 있는 내용은 1, 2, 3 번호와 화살표로.
- 버튼은 손가락으로 누르기 쉽게 크게.

■ 활동
- 회기마다 직접 해 보는 활동 1개 이상 (역할놀이, 따라 하기, 고르기).
- 설명 → 보여 주기 → 같이 하기 → 혼자 하기 순서.
- 끝에는 칭찬과 오늘 배운 것 한 가지 말하기.

■ 지키기
- 실제 이용인 이름·사진·사례는 넣지 않습니다. 가상 인물(예: 민수 씨)로.
- 전화번호·금액·장소는 지어내지 말고 [확인 필요]로 둡니다.

강의안으로 휴대폰 웹교안 만들기

핵심20분

PPT는 강사가 띄우는 자료, 웹교안은 이용인이 손에 쥐는 자료입니다. 기본을 먼저, 기능은 나중에.

프롬프트 1 — 기본 웹교안 (1차시 대화에서 이어서)
위 1회기 강의안으로 이용인이 휴대폰으로 보는 웹교안을 HTML 파일 하나로 만들어줘. - 쉬운교안지침.txt를 따르고, 화면은 세로 한 줄 - 단계마다 카드 한 장: 큰 이모지 + 짧은 문장 두 줄 이내 - 맨 아래 OX 퀴즈 3문제, 큰 O · X 단추를 누르면 "잘했어요!" 또는 다시 보기 안내 - 바깥 파일이나 인터넷 글꼴 없이 이 파일 하나로 - 맨 아래에 만든 날짜
  1. 오른쪽 창(아티팩트)에 바로 미리보기가 나와요 — 눌러 보며 확인
  2. 새 대화라면 강의안을 붙여 넣고 첫 줄을 아래 강의안으로로 바꿔 쓰기
  • 글이 길면 → 카드마다 문장을 한 줄씩 줄여줘. 나머지는 그대로 둬.
  • O · X 단추가 손가락으로 누르기 쉬운 크기인지

현장에선 이렇게 센터 활용

활동 전날 보호자 단톡방에 QR · 주소를 보내 미리 보기, 활동 뒤엔 복습. 사진 대신 이모지로 만들어 초상권 걱정 없이.

기능 붙이기 — 읽어 주기 · 칭찬 도장 · 반응형

15분

한 번에 하나씩, 끝엔 늘 "나머지는 그대로 둬".

기능 ① — 🔊 읽어 주기 단추
카드마다 🔊 읽어 주기 단추를 크게 붙여줘. 누르면 그 카드의 글을 한국어 목소리로 천천히 읽어 주게. 브라우저에 들어 있는 음성 기능을 쓰고, 나머지는 그대로 둬.
기능 ② — ⭐ 다 했어요 도장
카드마다 "다 했어요" 단추를 넣고, 누르면 ⭐ 도장이 찍히게 해줘. 모든 카드에 도장이 찍히면 맨 위에 "오늘도 멋져요! 🎉"가 크게 나오게. 나머지는 그대로 둬.
기능 ③ — 반응형 (TV · 노트북에서도)
화면 폭이 900px보다 넓으면 카드를 두 장씩 나란히 놓고 글씨를 더 크게 해줘. 휴대폰 화면 모양은 지금 그대로 둬.
  • 🔊 단추를 눌러 소리가 나는지 (휴대폰은 무음 모드를 풀고)
  • 미리보기 창을 넓혔다 좁혔다 — 두 줄 ↔ 한 줄로 바뀌는지
💡 반응형 = 파일은 하나, 화면 폭에 따라 모양이 바뀜. 주소도 QR도 하나로 휴대폰 · 센터 TV에 모두 씁니다.

인터넷에 올리기 — 버셀(Vercel Drop)

핵심15분

내 컴퓨터에만 있던 웹교안에 누구나 열 수 있는 주소가 생깁니다.

  1. 아티팩트 창 오른쪽 위 다운로드(또는 ⋯ → 다운로드)로 HTML 파일 받기
  2. 바탕화면에 웹교안 폴더를 만들고, 받은 파일을 넣어 이름을 index.html로 바꾸기
  3. index.html 더블클릭 — 내 컴퓨터에서 먼저 열려 보이는지
가입 (처음만)vercel.com/drop → Sign Up → Continue with Google → Hobby(무료) → 팀 이름은 영어로
올리기vercel.com/drop → 웹교안 폴더 통째로 끌어다 놓기
이름 = 주소Project Name 예) store-lesson-1 → Deploy
내 주소Continue to Project → Domains 아래 ○○○.vercel.app
🎬 버셀 화면으로 따라 하기 ↗

⚠ 올린 페이지는 누구나 볼 수 있어요. 이용인 이름 · 사진 · 연락처, 센터 내부 자료는 넣지 마세요. 고칠 땐 vercel.com/drop이 아니라 내 프로젝트 화면에 다시 올려야 주소가 그대로입니다.

가입 없이 바로 나누기

클로드 아티팩트 창의 게시(Publish)를 누르면 클로드 주소로 바로 공유할 수 있어요. 간단히 나눌 땐 이 방법도 좋습니다.

🟢 챗GPT로는 — 코드 복사 → 메모장 → index.html → 버셀은 똑같이 → 따라 하기 6

QR 코드 만들기 — 찍으면 열리는 교안

10분
프롬프트 2 — QR 만들기
[https://store-lesson-1.vercel.app] 로 가는 QR 코드를 크게 만들어 QR_웹교안.png 파일로 줘. QR 아래에 "찍으면 오늘 배운 내용이 열려요" 한 줄.
  • 내 휴대폰 카메라로 찍어서 내 웹교안이 열리는지
🛟 QR이 안 만들어지면 — 크롬에서 내 주소를 연 뒤 주소창 오른쪽 공유 → QR 코드 만들기 → 다운로드

1차시 PPT 마지막 장에 QR 넣기

⚡ PPT에 QR
올린 [편의점_1회기.pptx] (없으면 비상용 PPT) 맨 끝에 슬라이드를 한 장 더 만들어 QR_웹교안.png를 가운데 크게 넣고 "집에서 다시 봐요" 한 줄. 나머지 슬라이드는 그대로 두고 새 이름으로 저장해줘.

나만의 교안 스킬 만들기 — 다음엔 한 줄로

핵심25분

1차시에 본 pptx 스킬처럼, "우리 센터 교안은 이렇게 만든다"를 스킬로 저장합니다.

📄 SKILL.md가 뭐예요?

스킬의 설명서입니다. 메모장 글에 #는 제목, -는 목록 표시만 붙인 것. 클로드가 써 주니 외울 필요 없어요.

# 쉬운 교안 만들기
- 대상: 성인 발달장애인, 회당 40분
- 한 문장 한 가지, 큰 글씨, 그림과 함께
- 강의안 → PPT → 웹교안 순서로
- 실명 · 사례 금지, 모르는 값은 [확인 필요]
프롬프트 3 — 스킬로 묶기
이 대화에서 강의안 · PPT · 웹교안을 만든 방법을 스킬로 만들어줘. 이름은 easy-lesson. SKILL.md에 적을 것: - 대상 기본값: [성인 발달장애인, 회당 40분, 센터 활동실 TV] - 주제를 한 줄 받으면 ① 커리큘럼 ② 1회기 강의안 ③ PPT ④ 웹교안 순서로, 단계마다 내 확인을 받고 다음으로 - 쉬운교안지침.txt의 규칙 전부 - 웹교안 기능: 🔊 읽어 주기, ⭐ 다 했어요 도장, OX 퀴즈, 반응형 - 내가 자주 한 말: [더 쉬운 말로 / 나머지는 그대로 둬] 업로드용 zip 파일로 줘.
  1. zip 파일 다운로드
  2. 설정 → 사용자 지정 → 스킬 → ＋ → 스킬 만들기 → 스킬 업로드 → easy-lesson.zip
  3. 스킬 목록에서 easy-lesson이 켜져 있는지 확인
  • 안 올라가면 → 설정 → 기능에서 코드 실행 및 파일 생성이 켜져 있는지 보고, zip 안 폴더 이름을 easy-lesson으로 다시 묶어줘
  • zip이 안 만들어지면 → 비상용 easy-lesson.zip을 받아 올리기

🟢 챗GPT로는 — 스킬 내용을 '프로젝트 지시사항'에 붙여넣기 → 따라 하기 7

스킬로 새 주제 교안 — 한 줄이면 끝

15분

새 채팅을 열고 한 줄만. 1차시에 1시간 넘게 걸린 일이 몇 분으로 줄어드는지 느껴 보세요.

프롬프트 4 — 스킬로 한 줄
easy-lesson 스킬로 [안전하게 길 건너기] 교안을 만들어줘. 오늘은 ② 강의안과 ④ 웹교안까지만.
  • 새 웹교안에도 🔊 읽어 주기 · ⭐ 도장 · OX 퀴즈가 그대로 붙어 나오는지
  • 빠진 규칙이 있으면 → easy-lesson 스킬의 SKILL.md에 [규칙]을 추가해서 다시 zip으로 줘 → 다시 업로드
🛟 무료 한도 때문에 오늘은 강의안 · 웹교안만. PPT까지는 센터에서 한도가 다시 찬 뒤에 이어서 ③ PPT도 만들어줘.

오늘의 OX 퀴즈

5분
웹교안을 휴대폰용과 TV용으로 따로 만들어야 한다.

X — 반응형이면 파일 하나가 화면 폭에 맞춰 모양을 바꿔요.

버셀에 올린 웹교안은 주소를 아는 사람이면 누구나 볼 수 있다.

O — 그래서 이름 · 사진 · 연락처는 넣지 않아요.

고친 웹교안은 vercel.com/drop에 다시 올리면 QR이 그대로 맞는다.

X — drop은 새 주소를 만들어요. 내 프로젝트 화면에 다시 올립니다.

스킬을 만들어 두면 주제만 바꿔 한 줄로 같은 모양의 교안을 만들 수 있다.

O — 스킬은 만드는 법을 적어 둔 설명서입니다.

오늘 기억할 것 세 줄

1. PPT는 강사가 띄우고, 웹교안은 이용인이 손에 쥔다 — 주소 하나 · QR 하나

2. 기능은 하나씩, 끝엔 "나머지는 그대로 둬"

3. 잘 된 방법은 스킬로 — 다음 교안은 한 줄로

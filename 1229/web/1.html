복지현장에서 AI 쓸 때 세 가지 약속

10분
① 개인정보 금지이용인 실명 · 사진 · 사례 · 연락처, 상담기록은 넣지 않아요. 사례는 가상 인물(민수 씨)로 바꿔서.
② 사실 확인복지제도 기준 · 금액 · 전화번호는 AI가 틀리게 말할 수 있어요. 공식 출처로 다시 확인.
③ 결정은 내가AI는 초안. 우리 이용인에게 맞는지는 사회복지사가 판단합니다.

발달장애인 교안은 이렇게 쉬운 교안

  • 한 문장에 한 가지 · 짧고 쉬운 낱말 · 존댓말
  • 한 화면에 메시지 하나 · 큰 글씨 · 그림과 함께
  • 설명 → 보여 주기 → 같이 하기 → 혼자 하기

이 규칙을 매번 말하지 않도록 쉬운 교안 지침.txt에 적어 두었어요. 파일만 같이 올리면 됩니다.

대상 카드로 커리큘럼 → 1회기 강의안

핵심25분

먼저 대상 카드.txt를 내 수업에 맞게 고쳐요. 오늘은 예시(편의점에서 물건 사기)로 해도 됩니다.

프롬프트 1-1 — 커리큘럼 (두 파일 올리고)
올린 대상카드.txt의 참여자에게 맞는 교육 커리큘럼을 표로 만들어줘. 열: 회기 / 제목 / 목표 / 주요 내용 / 직접 해 보는 활동 / 준비물. 쉬운교안지침.txt를 따르고, 회기마다 직접 해 보는 활동을 1개 이상 넣어줘.
프롬프트 1-2 — 되묻기로 다듬기
참여자 중 [글을 거의 읽지 못하는 분이 3명] 있어. 이분들도 함께할 수 있게 커리큘럼을 고쳐줘. 바뀐 곳만 굵게 표시해줘.
프롬프트 1-3 — 1회기 강의안
이 커리큘럼의 [1]회기를 실제 수업에 쓸 강의안으로 만들어줘. 도입-전개-정리 순서로, 단계마다 시간(분) · 강사가 할 말 · 참여자 활동 · 준비물. 강사가 할 말은 참여자에게 직접 말하듯 쉬운 존댓말로. 마지막에 참여자가 어려워할 수 있는 점과 도와주는 방법 3가지.
  • 시간을 더하면 회당 시간(예: 40분)과 맞는지
  • 어려운 낱말이 남았으면 → [낱말]을 더 쉬운 말로 바꿔줘. 나머지는 그대로 둬.
  • 전화번호 · 금액이 들어갔으면 → 원본에 없는 값은 [확인 필요]로 바꿔줘

🟢 챗GPT로는 — 같은 프롬프트 그대로 → 따라 하기 1

강의안으로 PPT 교안 파일 만들기

핵심30분

같은 대화에서 이어서 부탁합니다. 한 번에 제대로 요청할수록 한도를 아낄 수 있어요.

프롬프트 2-1 — PPT 파일 만들기
위 1회기 강의안으로 수업 때 TV 화면에 띄울 PPT 파일(.pptx)을 만들어줘. - [10]장, 한 장에 메시지 하나 - 제목 44pt, 본문 32pt 이상, 흰 바탕에 진한 남색 글씨 - 장마다 내용을 보여 주는 큰 이모지나 단순한 그림 - 순서가 있는 내용은 1 → 2 → 3 화살표로 - 슬라이드 노트에 강사가 할 말 파일 이름은 [편의점_1회기].pptx로.
  1. 파일 카드의 다운로드 → 파워포인트(또는 한쇼·구글 슬라이드)로 열기
  2. 장을 넘기며 글자 크기 · 맞춤법 · 순서 확인
프롬프트 2-2 — 필요한 장만 고치기
[3]번 슬라이드만 고쳐줘: [글을 반으로 줄이고 그림을 더 크게]. 나머지 슬라이드는 그대로 두고 같은 이름으로 다시 저장해줘.
  • 슬라이드 노트(발표자 메모)에 강사가 할 말이 들어갔는지
  • 글이 넘치는 장이 있으면 → 글이 상자를 넘치는 장을 찾아서 줄여줘
🛟 한도에 걸렸거나 파일이 안 만들어지면 — 설정 → 기능의 코드 실행 및 파일 생성이 켜져 있는지 확인. 그래도 안 되면 비상용 PPT를 받아 4번을 함께 합니다.

사진이 있는 PPT

⚡ 내가 찍은 사진 넣기
올린 사진 [편의점 계산대.jpg]를 [5]번 슬라이드 왼쪽에 크게 넣고, 오른쪽에 "돈을 내요" 한 줄만. 나머지는 그대로 둬.

⚠ 이용인 얼굴이 나온 사진은 쓰지 않아요. 장소 · 물건 사진만.

🟢 챗GPT로는 — 파일이 안 만들어지면 개요를 받아 Gamma·Canva로 → 따라 하기 2

스킬의 이해 — PPT는 누가 만들었을까?

15분

방금 PPT를 만든 건 클로드에 들어 있는 기본 스킬(pptx) 덕분이에요. 스킬은 클로드의 업무 매뉴얼입니다.

  1. 설정 → 사용자 지정 → 스킬 — 이미 들어 있는 스킬 목록 보기
  2. 무엇이 있는지 확인하고 아래 표와 맞춰 보기
PPT (pptx)교육 교안 · 프로그램 설명회 자료
워드 (docx)보호자 안내문 · 프로그램 계획서 · 결과 보고서
엑셀 (xlsx)출석부 · 활동 기록표 · 만족도 결과 정리
PDF인쇄용 활동지 · 여러 파일 하나로 합치기
프롬프트 3 — 같은 강의안으로 보호자 안내문
위 커리큘럼으로 보호자께 보낼 프로그램 안내문을 워드 파일(.docx) A4 한 장으로 만들어줘. 프로그램 목적 · 4회기 일정표 · 가정에서 함께 해 주실 일 · 문의처. 날짜와 문의처는 [확인 필요]로 비워 두고, 정중한 존댓말로.
  • 하나의 강의안이 PPT · 안내문 · 활동지로 바뀌는 것 확인 — 재료는 하나, 결과물은 여러 개
💡 2차시에는 나만의 스킬을 직접 만들어요. "우리 센터 교안은 이렇게"를 한 번 적어 두면, 다음부터는 한 줄로.

활동지까지

⚡ 인쇄용 활동지
1회기에서 쓸 활동지를 PDF 한 장으로 만들어줘. 그림 보고 고르기 3문제, 동그라미 치는 칸을 크게. 쉬운교안지침.txt를 따라줘.

MCP 이해와 연결 — 카톡으로 받아 보기

20분

커넥터(MCP)는 클로드와 다른 프로그램을 잇는 연결선입니다. 오늘은 만든 결과를 내 카톡으로 받아 봅니다.

스킬클로드의 업무 매뉴얼 — 어떻게 만들지
커넥터(MCP)클로드의 손발 — 다른 프로그램에 직접 보내고 가져오기 (충전기 USB-C 같은 표준 규격)
무료 클로드내가 직접 추가하는 커넥터(사용자 정의) 1개까지 — 오늘은 카카오톡 하나

① 카카오 도구함 만들기

PlayMCP크롬에서 PlayMCP 검색 → playmcp.kakao.com → 오른쪽 위 로그인 → 카카오 로그인
담기'카카오톡 나챗방'(만든 곳 Kakao) → 도구함에 담기
주소 복사위쪽 도구함 → 도구함 주소(URL) 복사

② 클로드에 연결하기

커넥터설정 → 사용자 지정 → 커넥터 → ＋ → 사용자 정의 커넥터 추가
붙여넣기이름 카카오톡, 주소 칸에 복사한 주소 → 추가 → 연결 → 카카오 허용
켜기입력창 ＋ → 커넥터에서 카카오톡이 켜져 있는지
연결 확인 프롬프트
카카오톡 나와의 채팅방에 "클로드 연결 성공! 🎉" 이라고 보내줘.
프롬프트 4 — 오늘 만든 강의안 요약 보내기
오늘 만든 1회기 강의안을 수업 직전에 폰으로 볼 수 있게 시간 순서대로 다섯 줄로 줄여서 카카오톡 나와의 채팅방에 보내줘. 보내기 전에 보낼 글을 먼저 보여줘.
안 될 때 — 여기부터 보세요
도구함 주소가 안 보여요PlayMCP에 로그인했는지 → 도구함에 카카오톡 나챗방이 담겼는지
추가가 안 눌려요주소 앞뒤 빈칸 · 주소 전체가 복사됐는지 / 이미 다른 사용자 정의 커넥터가 있는지(무료는 1개)
"보낼 수 없어요"입력창 ＋ → 커넥터에서 카카오톡 켜기 → 새 채팅에서 다시
카톡이 안 와요허용을 눌렀는지, 폰과 같은 카카오 계정인지 · 채팅 목록에 나와의 채팅이 있는지

⚠ 커넥터는 내 계정에 들어가는 출입증이에요. 기관 업무 계정에 연결할 땐 기관 담당자와 먼저 상의하세요.
